# Contributing

Thank you for your interest in ANKIT'S FREE THROW ANALYSIS SOFTWARE.

## Ways to contribute

- Report reproducible bugs
- Improve compatibility with structured tracking formats
- Improve biomechanics validation
- Improve accessibility and user experience
- Add tests
- Improve documentation
- Propose new coach-readable reporting features

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused.
4. Run a Python syntax check on modified files.
5. Test the Blank Workspace and Executive Demo workflows.
6. Open a pull request describing the problem and solution.

## Data integrity

Do not submit private player data, confidential team data, credentials,
proprietary tracking files, or copyrighted datasets without permission.

## Demo-label disclaimer

Do not represent SPL Open Data trials as tracking collected from the
professional players whose names are used as portfolio labels.
